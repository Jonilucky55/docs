\<Info\>

This endpoint retrieves details of a specific subscription plan from the ASIA HR TEH system.

\</Info\>

## Request Example

\<RequestExample\>

\`\`\`bash cURL

curl -X GET 'https://api.asiahrteh.com/v1/plans/plan_asia_001' \\

  -H 'Authorization: Bearer YOUR_ASIA_HR_TEH_API_KEY' \\

  -H 'Content-Type: application/json'
