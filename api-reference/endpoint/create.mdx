\<Info\>

This endpoint allows you to create a new subscription plan for ASIA HR TEH users.

\</Info\>

## Request Example

\<RequestExample\>

\`\`\`bash cURL

curl -X POST 'https://api.asiahrteh.com/v1/plans' \\

  -H 'Content-Type: application/json' \\

  -H 'Authorization: Bearer YOUR_ASIA_HR_TEH_API_KEY' \\

  -d '{

    "name": "Premium Plan",

    "price": 49.99,

    "duration_months": 12

  }'
